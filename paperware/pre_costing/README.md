# Pre Costing Module

Pre Costing module for Paperware app - provides automated costing for paper and packaging products.

## Features

- 16+ item types supported (Cup, Box, Bag, Sheet, Lid)
- Automatic geometry calculation for each item type
- Integration with existing rate cards (Printing, Lamination, Die Cutting, Foaming)
- Multi-quantity comparison
- BOM and Quotation generation

## Item Types Supported

1. Paper Cup
2. Cup Holder
3. Cup Jacket
4. French Fry Cone
5. Plastic Lid
6. Meal Box
7. Outer Box
8. Tissue Box
9. Paper Bag
10. Table Paper Matt
11. Paper Leaflet
12. Paper Sticker
13. Business Card
14. Hand Tag
15. Memo Book
16. Enevolve

## Installation

1. Run `bench migrate` to install the module
2. Configure settings in Pre Costing Settings
3. Start creating Pre Costing Orders

## Usage

1. Create a new Pre Costing Order
2. Select item type and enter dimensions
3. System automatically calculates geometry and costs
4. Review cost summary and multi-quantity comparison
5. Submit and generate Quotation or BOM
